# java-calculator-precourse
***

## 문자열 계산기 (String Calculator)

입력된 문자열에서 숫자를 추출하여 합계를 계산하는 프로그램입니다.

---

## ✅ 구현 체크리스트

### view

- [x]  문자열 입력 받아서 전달한다.
- [x]  받은 결과 값을 출력

### 입력값 검사기
- 공통
- [x] 입력값이 없으면 예외 처리( 0 반환 )
- [x] 공백이 포함되어 있으면 예외처리
- [x] 커스텀 구분자가 있는지 확인


- 커스텀 구분자가 있을때:
- [x]  “//” , “\n” 사이에 있는지 확인
- [x]  구분자가 숫자이면 예외처리
- [x]  구분자 크기가 1이 아니라면 예외처리
- [x]  구분자가 .이면 예외처리(소수 입력에 지장)


- 커스텀 구분자가 없을 때:
- [x]  숫자로 시작하는지 확인


### 구분자 관리

- [x]  커스텀 구분자가 기본 구분자이면 예외 처리
- [x]  구분자를 넘겨주기

### 커스텀 구분자가 있을 때 구현

- [x]  커스텀 구분자 부분 잘라서 구분자 관리로 넘겨주기
- [x]  문자열에서 커스텀 구분자 입력 문자열 자르기


### 문자열 구분

- [x]  구분자를 사용해 구분자 분리
- [x]  분리한 문자 중 빈 곳이 있으면 예외처리
- [x]  분리한 문자 중 숫자가 아닌 것이 있으면 예외처리
- [x]  분리한 문자들을 숫자로 변환
- [x]  숫자 중 양수가 아니면 예외처리


### 덤셈기

- [x]  전달 받은 값을 더해 저장
- [x]  더한 값을 반올림하여 정수형으로 변환
- [x]  결과 값을 view에 전달
