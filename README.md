# java-calculator-precourse
***

## 문자열 계산기 (String Calculator)

입력된 문자열에서 숫자를 추출하여 합계를 계산하는 프로그램입니다.

---

## ✅ 구현 체크리스트

### view

- [x]  문자열 입력 받아서 전달한다.
- [ ]  받은 결과 값을 출력

### 입력값 검사기
- 공통
- [x] 입력값이 없으면 예외 처리( 0 반환 )
- [x] 공백이 포함되어 있으면 예외처리
- [x] 커스텀 구분자가 있는지 확인


- 커스텀 구분자가 있을때:
- [x]  “//” , “\n” 사이에 있는지 확인
- [x]  구분자가 숫자이면 예외처리
- [x]  구분자 크기가 1이 아니라면 예외처리
- [x]  구분자가 .이면 예외처리(소수 입력에 지장)
- [ ]  구분자가 기본 구분자와 중복 확인
- [ ]  커스텀 구분자 부분 잘라서 넘겨주기


- 커스텀 구분자가 없을 때:
- [ ]  숫자로 시작하는지 확인


### 구분자 관리

- [ ]  커스텀 구분자가 기본 구분자이면 추가하지 않음
- [ ]  구분자를 넘겨주기

### 문자열 구분

- [ ]  구분자를 사용해 구분자 분리
- [ ]  분리한 문자 중 빈 곳이 있으면 예외처리
- [ ]  분리한 문자들을 숫자로 변환
- [ ]  분리한 문자 중 숫자가 아닌 것이 있으면 예외처리
- [ ]  분리한 문자 중 0이 있으면 예외 처리
- [ ]  분리한 문자 중 음수가 있으면 예외처리
- [ ]  분리한 문자 중 소수가 있으면 예외 처리(다르게 저장 및 덧셈기 넘기기)
- [ ]  분리된 리스트를 덧셈기로 넘겨줌

### 덤셈기

- [ ]  전달 받은 값을 더해 저장
- [ ]  결과 값을 view에 전달
